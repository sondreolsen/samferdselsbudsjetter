# Investeringer i vei og jernbane 2013–2026

Oversikt over regjeringens forslag til investeringsbevilgninger til riksvei og jernbane i statsbudsjettene for 2013–2026 (Prop. 1 S Samferdselsdepartementet), med årlige tall, samlede tall, vekst i prosent, stortingsperioder og regional fordeling.

- `index.html` – selve nettsiden (frittstående, ingen eksterne avhengigheter)
- `tallgrunnlag.csv` – tallgrunnlaget (semikolonseparert, norsk tallformat)

Kilde: regjeringen.no. Alle beløp i nominelle kroner.
